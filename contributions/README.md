# Team Contributions

This folder documents who did what. Each member fills one file in
`individual_logs/` using the template below; `SUMMARY.md` aggregates them
for the final report.

## Template (`individual_logs/<name>.md`)

```markdown
# <Name> — Contribution Log

## Role
e.g. Data pipeline / Modelling / Evaluation / MLOps / Documentation

## Delivered
- [ ] file or artifact, one line each
- [ ] ...

## Evidence
- Commit / PR links:
- Experiment ids owned (`experiments/registry.csv`):
- Figures produced:

## Meetings / reviews
| Date | Topic | Outcome |
| --- | --- | --- |

## Open items handed over
- ...
```

## Rules

* One claim per line, each backed by a file path, a commit or an
  experiment id.
* Do not claim an experiment that has no `experiments/runs/<id>/`
  directory.
* If you reviewed someone else's work, say so explicitly under
  "Meetings / reviews".
